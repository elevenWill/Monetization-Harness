# CASE 07 — Whether to remain fully manual

## State

- `transactions.repeat_customers > 0` with evidence.
- Delivery repeats, but time cost and margin are unknown.

## Input

> 我现在还应该继续完全人工服务吗？

## Expected behavior

Use leverage design and a narrow business/economics check. Map and measure steps before choosing the first assisted or automated asset.

## Failure conditions

- Says either “stay manual forever” or “automate everything” without a process baseline.

# Local derived examples

## Zero-payment SaaS proposal

Instead of a three-month system build, offer a manually delivered outcome to ten qualified prospects over seven days. Cap spend, define a real price, and use completed payment—not praise—as the success signal.

## Resignation proposal

Preserve salary and essential runway while running a timeboxed evening/weekend paid test. Define the evidence threshold that would justify reconsidering resignation; “feeling committed” is not a threshold.

## One customer dependency

Test the same offer with independent buyers before automating custom work. A second customer is more informative than a second feature for the first customer.

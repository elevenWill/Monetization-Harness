# Local derived examples

These examples were authored for this Harness.

## “The product needs an admin dashboard”

- Fact: no buyer has paid.
- Assumption: a dashboard is required for purchase.
- Contradiction: “complete product” is being optimized before the purchase condition is known.
- Corrected question: what minimum presentation or manual process lets a qualified buyer decide whether to pay?

## “I need more research before selling”

Challenge only when the next research item is not tied to a named decision. Ask what observation would change the offer. If no answer exists, the research is probably avoidance; timebox a real offer instead.
